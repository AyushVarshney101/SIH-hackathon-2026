PROTOTYPE SCHEMA

Idea of wage wave is connecting idle farmland owners with unemployed farmers and farming machine owners to create a pool which can generate dividend to all.

Wage Wave:  
It a Django web app having a home page which highlights two things : 1. what we do (our goal); 2. who we are (mission of founders). home page will have link to register/log in page and current projects page.

Database: 
using the default database SQLite of Django. having a single table having only four columns: name, password, registering as, address.

Registration Page: 
Register form has following fields to be filled by user : name, username (must be unique) , registering as (a drop down menu having three options to select form: land owner, labour, idle farming machinery) {land size if land owner is selected, machines available if idle farming machinery is selected}, 2 line address, password, conformation password. Once registered user should automatically be logged in without the need to log in again.
Log In page should have only two fields username and password. if both field filled by user matches with respective entry in the database table. then user should get logged in.

Dashboard:
Once logged in user should automatically forwarded to a dashboard page having link to find work, profile, current projects pages in case of labour; list land, profile, current project pages in case of Land owners; contribute idle machinery, profile, current projects in case of idle farming machinery.

Current Projects Page : 

Current Projects page consists a list of projects each in different bordered containers.
A Project is a pool consists of land owners, farming machine contributors, manual labours. also having things listed like : list of different peoples doing different parts of the project, expected timeline, invested money, expected Revenue.

if user is logged in as anyone one of three types, he should be able to create a new project. there will be a + sing button on Current Project page to list a new project which lead to a form having fields like land owner's username, manual farmer's username, farming machine contributor's username, address, etc.
>>On creation of a new project the empty slots should gets listed to its respective sections For EXAMPLE - if somebody created a project but didn't fill the field of manual labour then there will be a job post created and listed in its respective section which is find work Page which is accessible by manual labours. 
also if someone is enrolled at any slot of some project he has the option to give rating to everyone after the project is done.

find work, contribute farming machinery, list land pages : 
simple pages where there is a filtered list for each group to select form. list contains jobs in different bordered containers having a enrole button at the bottom right corner of each container.

Profile Page:
contains all field user filled at time of registration.
list of jobs working on.
list of jobs he has done with the rating if given by other members of that project.
